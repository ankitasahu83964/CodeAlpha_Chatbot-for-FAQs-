# CodeAlpha FAQ Chatbot 🤖

## 📌 Description
This project is a simple FAQ Chatbot developed as part of the CodeAlpha AI Internship.  
It answers user queries by matching them with predefined frequently asked questions using basic NLP techniques.

---

## 🚀 Features
- Answers frequently asked questions automatically  
- Simple and interactive chat interface  
- Fast response using text matching  
- User-friendly design  

---

## 🧠 How It Works
- A dataset of FAQs (questions & answers) is stored  
- User input is processed and compared with stored questions  
- The most relevant answer is returned using similarity matching  

---

- HTML  
- CSS
